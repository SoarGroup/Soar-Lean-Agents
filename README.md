# Soar-Lean-Agents
Soar agents created from English -> Lean -> Soar

## Contents

- `STATUS.md`, `SOAR-LEAN-CONTEXT.md`: state of the Lean 4 specification of Soar (soar-lean) and working notes.
- `RESUME.md`: current status and next steps for the English-to-Soar and world-conventions work.
- `CMC/`: Lean specification of the Common Model of Cognition and its guides.
- `Slides/`: decks (From-English-to-Soar-CIC.pptx is the main one).
- `STEP6/`: round-trip results (Blind-Round-Trip-68.xlsx) and packages.
- `World-Conventions.xlsx`, `Soar-Conventions.xlsx`, `VisualSoar-Project-Conventions.docx`: conventions.
- `Library-Findings.docx`: findings on the agent library to address.
- `artists-world.zip`, `zebra-world.zip`: example tasks under the world conventions.
- `cmcsoar.zip`: the soar-lean project; `soar-agents-*.zip`: agent library test results.
