Resolution rules: STRING vs ENUMERATION -> STRING (open set of symbols); INTEGER vs FLOAT -> FLOAT; SOAR_ID vs a constant type -> SOAR_ID
(an attribute that has children in one datamap is an identifier there; the other datamap used it with a constant value, e.g. ^superstate nil).
