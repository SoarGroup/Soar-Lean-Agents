# Counting

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

Count upwards from a starting number to a target number, one at a time.

## This instance

count-up counts from 0 to 100; count-add-smem uses facts stored in semantic memory; count-in-substate counts in a
substate. These come from the Soar counting example agents rather than from a puzzle given to people.

## Note

There is no external human task beyond counting itself; the description follows the Soar example agents.
