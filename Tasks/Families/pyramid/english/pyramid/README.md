## Assumption ledger

- **A-PY1** (statements 2, 4): A problem object holds the next term (starting at the base, 5), the running sum (starting at 0) and the number of terms still to add after the next one (remaining, starting at the height, 10).
- **A-PY2** (statements 1, 2, 3): add-term adds the next term to the sum, lowers the term by 1 and lowers remaining by 1 (adding -1; WorldSpec has no subtraction, so a negative constant is added). It is proposed while remaining is 0 or more, which gives h + 1 terms.
- **A-PY3** (statements 5): "compute the sum": the goal is that every term has been added (remaining below 0); the sum is then on the problem object (0 for this instance).
