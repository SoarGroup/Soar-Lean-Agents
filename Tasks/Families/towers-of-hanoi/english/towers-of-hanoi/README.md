## Assumption ledger

- **A-TH1** (statements 1): Each disk (small, medium, large) has a size (1, 2, 3) and an on relation to the peg it is on; the order within a peg follows from the sizes, since a disk never rests on a smaller one.
- **A-TH2** (statements 2): "the top disk of a peg": the smallest disk on its peg (no smaller disk on the same peg), a derived relation top(disk, peg).
- **A-TH3** (statements 3): "an empty peg or a larger disk": the target peg has no disk smaller than the moved one (its top disk, if any, is larger), a derived relation can-take(peg, disk). Negations stay in derived relations, which the operators test positively (W-CHK-009).
- **A-TH4** (statements 4): "another peg": peg C, read from the original agent's initialize rules (the English does not name it; JL allowed reading initial states there).
- **A-TH5** (statements none): Search control, not from the English (as for the other WorldSpec search tasks): a look-ahead state that returns to a situation already on its path fails; a situation is where each disk is.
