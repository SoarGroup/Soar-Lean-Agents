# Soar agents written directly from English

Each agent here was written from an English task description alone, with no Lean step and no existing
Soar agent as a source. The English input for each is in `english-input.txt` in its folder.

`rosie-teaching/` holds a further 54 games and puzzles: the restricted-English teaching dialogs and world
states from the Rosie IJCAI 2019 teaching data. Twenty-seven of them have agents generated from the instructor statements (16 Nov 2026): tic-tac-toe, the nine block puzzles, the five river crossings and the twelve logic puzzles; three of them also through Lean (`rosie-teaching/LEAN-PATHS.md`). See `rosie-teaching/README.md` and `rosie-teaching/PILOT.md`.

| Folder | Task | Conventions | Library | How it runs |
|---|---|---|---|---|
| `artists-world/` | Artists and managers river crossing (N pairs) | World conventions | Shared library `Soar/soar-library` (v2.34) | `python3 run.py [seed]`; check with `check.py N` |
| `zebra-world/` | Five houses (zebra puzzle) | World conventions | Shared library (v2.34) | `python3 run.py [seed] \| python3 check.py` |
| `mc-world/` | Missionaries and cannibals | World conventions | Shared library (v2.34); sets `^iterative-step tie-impasse` | `python3 run.py mc-world missionaries-cannibals.soar 5000` |
| `wizards-world/` | Three wizards (the king's white spots) | World conventions | Shared library (v2.34) | `python3 run.py wizards-world three-wizards.soar 5000` |
| `three-mens-morris/` | Three Men's Morris, self-play | Pre-world-conventions | Local `selection.soar` (default selection space) | Generated by `gen.py` / `gen2.py`; `referee.py`, `battery2.py` |
| `UWM/` | UWM task descriptions, plus the first versions of missionaries and cannibals and three wizards | Pre-world-conventions (breadth-first search in working memory) | None | Standalone `.soar` files |

## Library path

The world-conventions packages load the shared library from `../../../Soar/soar-library`, which assumes
they sit at `Tasks/From-English/<package>`. To use another location, run
`SOAR_LIBRARY=/path/to/soar-library python3 gen.py`, which rewrites the loader.
