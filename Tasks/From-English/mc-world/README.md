# Missionaries and cannibals (world conventions, iterative deepening)

## Update, 15 November 2026: shared library v2.30

**Library.** This package no longer carries its own `lib/`. `missionaries-cannibals.soar` loads the shared library, Soar library v2.30, from `Soar/soar-library` in the Soar-Lean-Agents repository; the path (`../../../Soar/soar-library`) assumes this folder is unpacked in its place, `Tasks/From-English/mc-world`. To use another library location, run `SOAR_LIBRARY=/path/to/soar-library python3 gen.py`, which rewrites the loader. The flags are set with `^flag-override` (only the values that differ from the library defaults). The rules are those of test set v1.27 (`world__mc`); the earlier, library-specific notes below are kept as written and refer to the library copy embedded at the time (lib/ and its local fixes).

**Results with v2.30 (Soar 9.6.6, 15 Nov 2026).** `python3 run.py mc-world missionaries-cannibals.soar 5000` (from `Tasks/From-English`) reaches the goal in 11 crossings, the shortest, at decision 495.

---

- missionaries-cannibals.soar: loads agent-world, simple.soar, selection-world and
  selection-iterative-deepening from lib/, then the task rules.
- missionaries-cannibals-rules.soar: the task rules (generated by gen.py).
- lib/: the libraries used (the 8 Nov 2026 versions with the D-005 fix).
- run.py: runs the agent in Soar and plays the environment (marks each perform-action
  command complete). Usage: python3 run.py <this dir> missionaries-cannibals.soar 5000
