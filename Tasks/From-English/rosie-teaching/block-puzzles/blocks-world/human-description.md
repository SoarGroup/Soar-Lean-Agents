# Blocks world

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

Coloured blocks sit on a table, some stacked on others. You may move one block at a time, and only a block with
nothing on top of it; it can go onto the table or onto another block that has nothing on top of it.

Goal: rebuild the blocks into the target stacks.

## This instance

The target is a three-block tower: the red block on the green block and an orange block on the red block. Start and goal layouts: init-blocksworld.world, final-blocksworld.world.
