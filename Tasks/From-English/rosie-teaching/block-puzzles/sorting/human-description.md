# Colour sorting

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

Coloured blocks lie on coloured squares. Move blocks one at a time onto squares so that every block ends on a square of its own colour.

## This instance

Red, blue and green blocks and squares (init-sorting.world, final-sorting.world).

## Note

A simple sorting task from the Rosie puzzle archive; it has no standard published statement.
