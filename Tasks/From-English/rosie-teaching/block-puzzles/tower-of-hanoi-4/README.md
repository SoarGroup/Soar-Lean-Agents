# Tower of Hanoi (4 blocks): Soar agent from the Rosie teaching script

**Runnable, but does not solve the task:** the shortest solution has 15 moves, more than the depth limit of 12 of the library's look-ahead (a library limit, World-Conventions-Spec v6 section 6). `tower-of-hanoi-4.soar` loads the shared library (`Soar/soar-library`, v2.34) and `tower-of-hanoi-4-rules.soar` (11 task rules, generated by `gen.py` from the statements in `english-input.txt`). Needs Soar 9.6.6.

## Run

    python3 ../../tools/run_agent.py . tower-of-hanoi-4.soar --seed 1 --cap 500000
    python3 ../../tools/run_agent.py . tower-of-hanoi-4.soar --json | python3 ../../tools/check_plan.py tower-of-hanoi-4 init-tower4.world

`gen.py` regenerates the rules (`tools/rosie_tasks.py`, function `hanoi`); `python3 gen.py WORLD` writes the same rules with
another example state as the initial world, for the state checks.

## Assumption ledger (places where the English is open)

| ID | Reading |
|---|---|
| A-H1 | "clear" is defined for a location ("If a location is not below an object") but used for "a clear block". Read as: any object that is not below an object is clear. |
| A-H4 | "move X onto Y": X's on relation and the matching below relation now name Y; the object X left becomes clear. |
| A-H2 | "larger than" is defined with the block as subject and used with the object as subject. Read as: X is larger than Y when X's volume is more than Y's. |
| A-H3 | "two clear green locations": two different green locations, both clear (the world has exactly two). |
| A-H5 | The action has no name in the dialog; it is called `move`. |

Convention notes: `clear` is a maintained one-argument relation (W-SPEC v6 section 3); `larger than` is expanded in place; the goal is `^goal-met` on the task object.

**Named gap (library limit, load-bearing).** The shortest solution has 15 moves; iterative deepening stops at depth 12, and before that the unpruned search grows by about a factor of three per level (3 blocks, depth 7: 35,000 decisions). The translation is complete and its goal test is right on both example states; solving needs either a look-ahead beyond the limit or knowledge that the instructions do not give (for example, subgoals such as moving the largest block first).
