Small Othello: English input (Rosie teaching script)

The instructor's statements to Rosie, verbatim and in order (script.txt). "Load <name>" sets up the world state in <name>.world in this folder. A bare "Ok." from the instructor answers Rosie's request to set up a state (the puzzle, a failure condition or the goal), "Done." ends the teaching, and the final "No." declines Rosie's offer to solve the task. Rosie's side of the dialog is in dialog.txt; dialog.html shows the dialog with pictures of the world states.

Teaching script:
  1. The name of the game is othello.
  2. Load init-othello.   [world state: init-othello.world]
  3. Ok.
  4. If the locations between a clear location and a captured location are occupied then you can move an available red block onto the clear location.
  5. If a block is not on a location then it is available.
  6. If a location is below a red block then it is captured.
  7. If a location is not below an object then it is clear.
  8. If a location is below a blue block then it is occupied.
  9. Load final-othello.   [world state: final-othello.world]
 10. The goal is that all locations are covered and the number of captured locations is more than the number of occupied locations.
 11. Ok.
 12. If a location is below an object then it is covered.
 13. Load fail-othello.   [world state: fail-othello.world]
 14. If all the locations are covered and the number of occupied locations is more than the number of captured locations then you lose.
 15. Ok.
 16. Done.
 17. No.

World vocabulary (extracted from the world files loaded above; not part of the dialog):
  Object categories: block, location
  Object attributes: color (blue1, red1); x (numeric, 1 to 4); y (numeric, 1 to 4)
  Relations: below1, on1
  Names are as written in the world files, including their trailing 1 (red1, on1).

Source: IJCAI 2019 teaching data for games and puzzles, teaching-data/board-games/mini-othello/.
