# Tic-tac-toe

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

Two players take turns marking empty squares of a 3 x 3 grid, one with X and the other with O. The first to get three
of their marks in a row, column or diagonal wins; if all nine squares fill with no line, the game is a draw.

## This instance

The agent plays red against an opponent; three red blocks in a row win (init-tictactoerc.world).
