Knight's Tour: English input (Rosie teaching script)

The instructor's statements to Rosie, verbatim and in order (script.txt). "Load <name>" sets up the world state in <name>.world in this folder. A bare "Ok." from the instructor answers Rosie's request to set up a state (the puzzle, a failure condition or the goal), "Done." ends the teaching, and the final "No." declines Rosie's offer to solve the task. Rosie's side of the dialog is in dialog.txt; dialog.html shows the dialog with pictures of the world states.

Teaching script:
  1. The name of the puzzle is knights-tour.
  2. Load init-atour2.   [world state: init-atour2.world]
  3. Ok.
  4. If a clear location is movable from a captured location then you can move a red block onto the clear location and move an available clear blue block onto the captured location.
  5. If a block is not on a location then it is available.
  6. If a location is not below an object then it is clear.
  7. If a location is below a red block then it is captured.
  8. If a location that is alongside a captured location is diagonal with an object that is not next to the captured location then the object is movable from the captured location.
  9. The solution has eleven steps.
 10. Load final-atour2.   [world state: final-atour2.world]
 11. The goal is that all locations are covered.
 12. Ok.
 13. If a location is below an object then it is covered.
 14. Done.
 15. No.

World vocabulary (extracted from the world files loaded above; not part of the dialog):
  Object categories: block, location
  Object attributes: color (blue1, green1, red1); column (numeric, 1 to 4); row (numeric, 1 to 3)
  Relations: alongside1, below1, diagonal-with1, near1, on1
  Names are as written in the world files, including their trailing 1 (red1, on1).

Source: IJCAI 2019 teaching data for games and puzzles, teaching-data/chess-problems/knights-tour/.
