N Knights: English input (Rosie teaching script)

The instructor's statements to Rosie, verbatim and in order (script.txt). "Load <name>" sets up the world state in <name>.world in this folder. A bare "Ok." from the instructor answers Rosie's request to set up a state (the puzzle, a failure condition or the goal), "Done." ends the teaching, and the final "No." declines Rosie's offer to solve the task. Rosie's side of the dialog is in dialog.txt; dialog.html shows the dialog with pictures of the world states.

Teaching script:
  1. The name of the puzzle is n-knights.
  2. Load init-nknights2.   [world state: init-nknights2.world]
  3. Ok.
  4. The name of an action is place-block.
  5. You can move a clear available block onto a clear location.
  6. If a block is not on a location then it is available.
  7. If a location is not below an object then it is clear.
  8. The solution has eight steps.
  9. Load fail-nknights2.   [world state: fail-nknights2.world]
 10. If a block is jumpable by another block then you lose.
 11. Ok.
 12. If an object that is alongside a block is diagonal with a location that is not next to the block then the location is jumpable by the block.
 13. Load final-nknights2.   [world state: final-nknights2.world]
 14. The name of the goal is all-placed.
 15. Ok.
 16. The goal is that all blocks are placed.
 17. If a block is on a location then the block is placed.
 18. Done.
 19. No.

World vocabulary (extracted from the world files loaded above; not part of the dialog):
  Object categories: block, location
  Object attributes: color (blue1); column (numeric, 1 to 4); row (numeric, 1 to 4)
  Relations: alongside1, below1, diagonal-with1, near1, on1
  Names are as written in the world files, including their trailing 1 (red1, on1).

Source: IJCAI 2019 teaching data for games and puzzles, teaching-data/chess-problems/n-knights/.
