# N knights

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

Place pieces on an empty chessboard so that no two attack each other under the chess move of that piece:
- queens: no two in the same row, column or diagonal;
- rooks: no two in the same row or column;
- kings: no two on neighbouring squares (including diagonal neighbours);
- knights: no two a knight's move apart.

## This instance

Eight knights on a 4 x 4 board (init-nknights2.world).
