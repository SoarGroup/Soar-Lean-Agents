Eight Puzzle: English input (Rosie teaching script)

The instructor's statements to Rosie, verbatim and in order (script.txt). "Load <name>" sets up the world state in <name>.world in this folder. A bare "Ok." from the instructor answers Rosie's request to set up a state (the puzzle, a failure condition or the goal), "Done." ends the teaching, and the final "No." declines Rosie's offer to solve the task. Rosie's side of the dialog is in dialog.txt; dialog.html shows the dialog with pictures of the world states.

Teaching script:
  1. The name of the puzzle is eight-puzzle.
  2. Load init-8puzzlerc.   [world state: init-8puzzlerc.world]
  3. Ok.
  4. The name of the action is slide-block.
  5. If a block is adjacent to a clear location then you can move the block onto the clear location.
  6. If a location is not below an object then it is clear.
  7. If a location is next to an object but it is not diagonal with the object then it is adjacent to the object.
  8. Load final-8puzzlerc.   [world state: final-8puzzlerc.world]
  9. The goal is that there are eight matched locations.
 10. Ok.
 11. If the color of a location is the color of the block that is on the location then the location is matched.
 12. Done.
 13. No.

World vocabulary (extracted from the world files loaded above; not part of the dialog):
  Object categories: block, location
  Object attributes: color (blue1, brown1, gray1, green1, orange1, purple1, red1, yellow1); column (numeric, 1 to 3); row (numeric, 1 to 3)
  Relations: below1, diagonal-with1, near1, on1
  Names are as written in the world files, including their trailing 1 (red1, on1).

Source: IJCAI 2019 teaching data for games and puzzles, teaching-data/grid-puzzles/eight-puzzle/.
