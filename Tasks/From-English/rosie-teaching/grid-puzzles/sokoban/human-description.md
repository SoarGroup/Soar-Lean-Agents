# Sokoban

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

You walk on a grid of floor squares, one square at a time up, down, left or right. Some squares hold boxes and some are
marked as storage. Walking into a box pushes it one square forward if the square beyond is free; you can never pull a
box or push two at once.

Goal: push every box onto a storage square.
