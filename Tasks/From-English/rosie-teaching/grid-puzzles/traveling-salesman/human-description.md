# Grid tour (travelling salesman)

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

A salesman moves around a grid one square at a time, up, down, left or right, leaving a marker on each square he
leaves. He may not enter a marked square.

Goal: visit every square exactly once.

## This instance

A 3 x 4 grid; the salesman is the red block and the markers are blue blocks (init-tourrc.world).

## Note

A one-square-at-a-time tour of a grid (a Hamiltonian path), called travelling salesman in the Rosie archive.
