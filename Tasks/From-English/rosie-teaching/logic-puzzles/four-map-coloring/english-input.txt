4 Map Coloring: English input (Rosie teaching script)

The instructor's statements to Rosie, verbatim and in order (script.txt). "Load <name>" sets up the world state in <name>.world in this folder. A bare "Ok." from the instructor answers Rosie's request to set up a state (the puzzle, a failure condition or the goal), "Done." ends the teaching, and the final "No." declines Rosie's offer to solve the task. Rosie's side of the dialog is in dialog.txt; dialog.html shows the dialog with pictures of the world states.

Teaching script:
  1. The name of the puzzle is number-map-color.
  2. Load init-map-ncolor3rc.   [world state: init-map-ncolor3rc.world]
  3. Ok.
  4. The name of the action is write-1-to-4.
  5. You can write a number that is between one and four onto an empty location.
  6. If the value of a location is absent then the location is empty.
  7. Load fail-map-ncolorrc.   [world state: fail-map-ncolorrc.world]
  8. If the value of a location is the value of an object that is next to the location then you lose.
  9. Ok.
 10. The solution has three steps.
 11. Load final-map-ncolorrc.   [world state: final-map-ncolorrc.world]
 12. The name of the goal is all-filled.
 13. Ok.
 14. The goal is that all locations are filled.
 15. If the value of a location is more than zero then the location is filled.
 16. Done.
 17. No.

World vocabulary (extracted from the world files loaded above; not part of the dialog):
  Object categories: location
  Object attributes: column (numeric, 1 to 3); row (numeric, 1 to 3); value (numeric, 1 to 4)
  Relations: near1
  Names are as written in the world files, including their trailing 1 (red1, on1).

Source: IJCAI 2019 teaching data for games and puzzles, teaching-data/logic-puzzles/four-map-coloring/.
