# Map colouring

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

Colour each region of a map so that no two regions that share a border have the same colour, using at most four colours.

## This instance

The colours are written as the numbers 1 to 4 (init-map-ncolor3rc.world).
