# Jigsaw sudoku (4 x 4)

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

Fill the grid with the numbers 1 to 4 so that every row, every column and every outlined region contains each number
exactly once. The regions are irregular shapes rather than square boxes.

Grid and regions: init-jigsawdoku.world.
