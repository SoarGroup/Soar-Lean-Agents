Kakuro: English input (Rosie teaching script)

The instructor's statements to Rosie, verbatim and in order (script.txt). "Load <name>" sets up the world state in <name>.world in this folder. A bare "Ok." from the instructor answers Rosie's request to set up a state (the puzzle, a failure condition or the goal), "Done." ends the teaching, and the final "No." declines Rosie's offer to solve the task. Rosie's side of the dialog is in dialog.txt; dialog.html shows the dialog with pictures of the world states.

Teaching script:
  1. The name of the puzzle is kakuro.
  2. Load init-kakuro.   [world state: init-kakuro.world]
  3. Ok.
  4. The name of the action is write-1-to-9.
  5. You can write a number that is between one and nine onto an empty location.
  6. If the value of a location is absent then the location is empty.
  7. The solution has four steps.
  8. Load final-kakuro.   [world state: final-kakuro.world]
  9. The name of the goal is all-filled.
 10. Ok.
 11. The goal is that all locations are filled.
 12. If the value of a location is more than zero then the location is filled.
 13. Load fail-kakuro.   [world state: fail-kakuro.world]
 14. If two of the green locations are identical and they have the same row then you lose.
 15. Ok.
 16. If the locations have the same value then they are identical.
 17. If two of the green locations are identical and they have the same column then you lose.
 18. Ok.
 19. If the green locations in a file are filled and the sum of the values of the file is not the value of a location that is atop the file then you lose.
 20. Ok.
 21. If the blocks have the same column then they are in a file.
 22. If a block is blue and the column of the block is the column of a location then the block is atop the location.
 23. If the green locations in a rank are filled and the sum of the values of the rank is not the value of a location that is aside the rank then you lose.
 24. Ok.
 25. If the blocks have the same row then they are in a rank.
 26. If a block is yellow and the row of the block is the row of a location then the block is aside the location.
 27. Done.
 28. No.

World vocabulary (extracted from the world files loaded above; not part of the dialog):
  Object categories: location
  Object attributes: color (black1, blue1, green1, yellow1); column (numeric, 1 to 4); row (numeric, 1 to 5); value (numeric, 1 to 23)
  Relations: none
  Names are as written in the world files, including their trailing 1 (red1, on1).

Source: IJCAI 2019 teaching data for games and puzzles, teaching-data/logic-puzzles/kakuro/.
