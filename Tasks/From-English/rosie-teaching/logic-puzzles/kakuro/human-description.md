# Kakuro

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

A grid like a crossword, with clue cells and empty cells. Fill each empty cell with a digit from 1 to 9 so that each
horizontal or vertical run of empty cells adds up to the clue for that run, with no digit repeated within a run.
