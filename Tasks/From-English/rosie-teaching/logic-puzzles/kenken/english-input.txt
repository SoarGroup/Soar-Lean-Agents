KenKen: English input (Rosie teaching script)

The instructor's statements to Rosie, verbatim and in order (script.txt). "Load <name>" sets up the world state in <name>.world in this folder. A bare "Ok." from the instructor answers Rosie's request to set up a state (the puzzle, a failure condition or the goal), "Done." ends the teaching, and the final "No." declines Rosie's offer to solve the task. Rosie's side of the dialog is in dialog.txt; dialog.html shows the dialog with pictures of the world states.

Teaching script:
  1. The name of the puzzle is color-ken-ken.
  2. Load init-color-ken.   [world state: init-color-ken.world]
  3. Ok.
  4. The name of the action is write-1-to-4.
  5. You can write a number that is between one and four onto an empty location.
  6. If the value of a location is absent then the location is empty.
  7. The solution has four steps.
  8. Load fail-color-ken2.   [world state: fail-color-ken2.world]
  9. The name of a failure is same-row-value.
 10. Ok.
 11. If the row of a location is the row of a location and the value of the former location is the value of the latter location then you lose.
 12. The name of a failure is same-col-value.
 13. Ok.
 14. If the column of a location is the column of a location and the value of the former location is the value of the latter location then you lose.
 15. Load final-color-ken.   [world state: final-color-ken.world]
 16. The name of the goal is all-filled.
 17. Ok.
 18. The goal is that all locations are filled.
 19. If the value of a location is more than zero then the location is filled.
 20. Load fail-color-ken.   [world state: fail-color-ken.world]
 21. The name of a failure is group-sum-10.
 22. Ok.
 23. If the locations in a group are filled and the sum of the values of the group is not ten then you lose.
 24. If the blocks have the same color then they are in a group.
 25. Done.
 26. No.

World vocabulary (extracted from the world files loaded above; not part of the dialog):
  Object categories: location
  Object attributes: color (blue1, green1, red1, yellow1); column (numeric, 1 to 4); row (numeric, 1 to 4); value (numeric, 1 to 5)
  Relations: none
  Names are as written in the world files, including their trailing 1 (red1, on1).

Source: IJCAI 2019 teaching data for games and puzzles, teaching-data/logic-puzzles/kenken/.
