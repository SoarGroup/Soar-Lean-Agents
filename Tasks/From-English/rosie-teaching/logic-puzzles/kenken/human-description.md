# KenKen (coloured cages)

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

Fill an n x n grid with the numbers 1 to n so that no number repeats in any row or column. The grid is divided into
outlined groups of cells called cages; each cage shows a target number and an operation (+, -, x or /). The numbers in a
cage, combined with that operation in any order, must give the target. A single-cell cage simply contains its target.
A number may repeat within a cage if the repeats are in different rows and columns.

## This instance

A 4 x 4 puzzle whose cages are shown by colour (init-color-ken.world).
