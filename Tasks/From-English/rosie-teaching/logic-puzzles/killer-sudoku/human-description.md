# Killer sudoku (4 x 4)

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

Sudoku rules apply: every row, column and box contains each number once. In addition the grid is divided into cages
with a total; the numbers in a cage must add up to its total, and no number repeats within a cage.

## This instance

Numbers 1 to 4 (init-killer-sudoku.world).
