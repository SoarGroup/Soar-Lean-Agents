# Logi-5

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

Fill the grid so that each number appears exactly once in every row, every column and every coloured region; the
regions are irregular shapes of the same size.

## This instance

This instance uses the numbers 1 to 4 (init-logi5.world).

## Note

Published Logi-5 puzzles are 5 x 5 with the numbers 1 to 5 (or letters A to E); this Rosie instance is smaller.
