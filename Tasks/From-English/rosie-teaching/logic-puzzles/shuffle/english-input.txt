Shuffle: English input (Rosie teaching script)

The instructor's statements to Rosie, verbatim and in order (script.txt). "Load <name>" sets up the world state in <name>.world in this folder. A bare "Ok." from the instructor answers Rosie's request to set up a state (the puzzle, a failure condition or the goal), "Done." ends the teaching, and the final "No." declines Rosie's offer to solve the task. Rosie's side of the dialog is in dialog.txt; dialog.html shows the dialog with pictures of the world states.

Teaching script:
  1. The name of the puzzle is shuffle.
  2. Load init-shuffle.   [world state: init-shuffle.world]
  3. Ok.
  4. The name of the action is write-1-to-9.
  5. You can write a number that is between one and nine onto an empty location.
  6. If the value of a location is absent then the location is empty.
  7. The solution has three steps.
  8. Load final-shuffle.   [world state: final-shuffle.world]
  9. The name of the goal is all-filled.
 10. Ok.
 11. The goal is that all locations are filled.
 12. If the value of a location is more than zero then the location is filled.
 13. Load fail-shuffle.   [world state: fail-shuffle.world]
 14. The name of a failure is file-sum.
 15. Ok.
 16. If the green locations in a file are filled and the sum of the values of the file is not the value of a location that is beneath the file then you lose.
 17. If the blocks have the same column then they are in a file.
 18. If a block is blue and the column of the block is the column of a location then the block is beneath the location.
 19. The name of a failure is rank-sum.
 20. Ok.
 21. If the green locations in a rank are filled and the sum of the values of the rank is not the value of a location that is beside the rank then you lose.
 22. If the blocks have the same row then they are in a rank.
 23. If a block is blue and the row of the block is the row of a location then the block is beside the location.
 24. Done.
 25. No.

World vocabulary (extracted from the world files loaded above; not part of the dialog):
  Object categories: location
  Object attributes: color (black1, blue1, green1); column (numeric, 1 to 4); row (numeric, 1 to 4); value (numeric, 1 to 17)
  Relations: none
  Names are as written in the world files, including their trailing 1 (red1, on1).

Source: IJCAI 2019 teaching data for games and puzzles, teaching-data/logic-puzzles/shuffle/.
