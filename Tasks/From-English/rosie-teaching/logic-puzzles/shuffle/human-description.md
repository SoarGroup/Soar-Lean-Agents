# Row and column sums

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

Fill the empty cells with numbers from 1 to 9 so that each row adds up to the total beside it and each column adds up to
the total beneath it.

## This instance

Grid and totals: init-shuffle.world.

## Note

Named shuffle in the Rosie archive; it is a Survo-like sum puzzle without the use-each-number-once rule.
