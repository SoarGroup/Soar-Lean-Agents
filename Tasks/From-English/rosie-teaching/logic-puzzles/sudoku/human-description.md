# Mini sudoku (4 x 4)

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

Fill a 4 x 4 grid with the numbers 1 to 4 so that every row, every column and each of the four 2 x 2 boxes contains each
number exactly once. Some numbers are given.
