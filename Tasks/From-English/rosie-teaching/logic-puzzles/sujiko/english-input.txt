Sujiko: English input (Rosie teaching script)

The instructor's statements to Rosie, verbatim and in order (script.txt). "Load <name>" sets up the world state in <name>.world in this folder. A bare "Ok." from the instructor answers Rosie's request to set up a state (the puzzle, a failure condition or the goal), "Done." ends the teaching, and the final "No." declines Rosie's offer to solve the task. Rosie's side of the dialog is in dialog.txt; dialog.html shows the dialog with pictures of the world states.

Teaching script:
  1. The name of the puzzle is sujiko.
  2. Load init-sujiko.   [world state: init-sujiko.world]
  3. Ok.
  4. The name of the action is write-1-to-9.
  5. You can write a number that is between one and nine onto an empty location.
  6. If the value of a location is absent then the location is empty.
  7. The solution has four steps.
  8. Load final-sujiko.   [world state: final-sujiko.world]
  9. The name of the goal is all-filled.
 10. Ok.
 11. The goal is that all locations are filled.
 12. If the value of a location is more than zero then the location is filled.
 13. Load fail-sujiko.   [world state: fail-sujiko.world]
 14. If the value of a location is the value of another location then you lose.
 15. Ok.
 16. If the locations in a grouping are filled and the sum of the values of the grouping is not the value of a block that is above the grouping then you lose.
 17. Ok.
 18. If a block is filled and their locations are under the block then they are in a grouping.
 19. Done.
 20. No.

World vocabulary (extracted from the world files loaded above; not part of the dialog):
  Object categories: block, location
  Object attributes: column (numeric, 1 to 3); row (numeric, 1 to 3); value (numeric, 1 to 18)
  Relations: above1, under1
  Names are as written in the world files, including their trailing 1 (red1, on1).

Source: IJCAI 2019 teaching data for games and puzzles, teaching-data/logic-puzzles/sujiko/.

Learning: do not learn from look-ahead. With learning on no seed finishes within 300 s; without it it solves in 12,273-16,115 decisions (library v2.45).
