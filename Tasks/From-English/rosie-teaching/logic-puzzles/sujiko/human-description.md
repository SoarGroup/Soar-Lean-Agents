# Sujiko

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

Place the numbers 1 to 9, each once, in a 3 x 3 grid. Four circles sit where four cells meet; the four cells around each
circle must add up to the number in the circle.
