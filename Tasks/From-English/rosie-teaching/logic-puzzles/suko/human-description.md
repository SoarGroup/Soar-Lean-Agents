# Suko

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

Place the numbers 1 to 9, each once, in a 3 x 3 grid. As in Sujiko, the four cells around each of four circles must add
up to the circle's number; in addition the cells are shaded in colours, and the cells of each colour must add up to the
total given for that colour.
