Survo: English input (Rosie teaching script)

The instructor's statements to Rosie, verbatim and in order (script.txt). "Load <name>" sets up the world state in <name>.world in this folder. A bare "Ok." from the instructor answers Rosie's request to set up a state (the puzzle, a failure condition or the goal), "Done." ends the teaching, and the final "No." declines Rosie's offer to solve the task. Rosie's side of the dialog is in dialog.txt; dialog.html shows the dialog with pictures of the world states.

Teaching script:
  1. The name of the puzzle is survo.
  2. Load init-survo2.   [world state: init-survo2.world]
  3. Ok.
  4. You can write a number that is between one and twelve onto an empty location.
  5. If the value of a location is absent then the location is empty.
  6. The solution has four steps.
  7. Load final-survo.   [world state: final-survo.world]
  8. The name of the goal is all-filled.
  9. Ok.
 10. The goal is that all locations are filled.
 11. If the value of a location is more than zero then the location is filled.
 12. Load fail-survo.   [world state: fail-survo.world]
 13. If the value of a green location is the value of another green location then you lose.
 14. Ok.
 15. The name of a failure is file-sum.
 16. Ok.
 17. If the green locations in a file are filled and the sum of the values of the file is not the value of a location that is beneath the file then you lose.
 18. If the blocks have the same column then they are in a file.
 19. If a block is blue and the column of the block is the column of a location then the block is beneath the location.
 20. The name of a failure is rank-sum.
 21. Ok.
 22. If the green locations in a rank are filled and the sum of the values of the rank is not the value of a location that is beside the rank then you lose.
 23. If the blocks have the same row then they are in a rank.
 24. If a block is blue and the row of the block is the row of a location then the block is beside the location.
 25. Done.
 26. No.

World vocabulary (extracted from the world files loaded above; not part of the dialog):
  Object categories: location
  Object attributes: color (black1, blue1, green1); column (numeric, 1 to 5); row (numeric, 1 to 4); value (numeric, 1 to 30)
  Relations: none
  Names are as written in the world files, including their trailing 1 (red1, on1).

Source: IJCAI 2019 teaching data for games and puzzles, teaching-data/logic-puzzles/survo/.

Learning: do not learn from look-ahead. With learning on no seed finishes within 300 s; without it it solves in 4,775-5,100 decisions (library v2.45).
