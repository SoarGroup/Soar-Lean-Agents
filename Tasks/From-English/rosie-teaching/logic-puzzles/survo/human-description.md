# Survo

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

Fill a table with the numbers 1 to n (n = the number of cells), each used once, so that every row and every column adds
up to the totals written at its end. Some numbers may be given.

## This instance

This instance uses the numbers 1 to 12 (init-survo2.world).
