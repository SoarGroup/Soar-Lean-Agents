Knight Corner Swapping: English input (Rosie teaching script)

The instructor's statements to Rosie, verbatim and in order (script.txt). "Load <name>" sets up the world state in <name>.world in this folder. A bare "Ok." from the instructor answers Rosie's request to set up a state (the puzzle, a failure condition or the goal), "Done." ends the teaching, and the final "No." declines Rosie's offer to solve the task. Rosie's side of the dialog is in dialog.txt; dialog.html shows the dialog with pictures of the world states.

Teaching script:
  1. The name of the puzzle is knight-swap.
  2. Load init-kswap2.   [world state: init-kswap2.world]
  3. Ok.
  4. If a clear location is jumpable by a block then you can move the block onto the clear location.
  5. If a location is not below an object then it is clear.
  6. If an object that is alongside a block is diagonal with a location that is not next to the block then the location is jumpable by the block.
  7. The solution has four steps.
  8. Load final-kswap2.   [world state: final-kswap2.world]
  9. The name of the goal is red-blue-matched.
 10. Ok.
 11. The goal is that all the red blocks are on the red locations and all the blue blocks are on the blue locations.
 12. Done.
 13. No.

World vocabulary (extracted from the world files loaded above; not part of the dialog):
  Object categories: block, location
  Object attributes: color (blue1, red1); column (numeric, 1 to 3); row (numeric, 1 to 3)
  Relations: alongside1, below1, diagonal-with1, near1, on1
  Names are as written in the world files, including their trailing 1 (red1, on1).

Other world files in this folder, not loaded in the dialog: third-kswap2.world

Source: IJCAI 2019 teaching data for games and puzzles, teaching-data/side-swapping-puzzles/4-corner-knights/.
