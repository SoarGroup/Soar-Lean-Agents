Mahjong: English input (Rosie teaching script)

The instructor's statements to Rosie, verbatim and in order (script.txt). "Load <name>" sets up the world state in <name>.world in this folder. A bare "Ok." from the instructor answers Rosie's request to set up a state (the puzzle, a failure condition or the goal), "Done." ends the teaching, and the final "No." declines Rosie's offer to solve the task. Rosie's side of the dialog is in dialog.txt; dialog.html shows the dialog with pictures of the world states.

Teaching script:
  1. The name of the puzzle is mahjong.
  2. Load init-mahjong.   [world state: init-mahjong.world]
  3. Ok.
  4. If the color of a clear available block is the color of another clear available block then you can move the blocks onto a garbage.
  5. If a block is not on a location then it is available.
  6. If a location is not below an object then it is clear.
  7. Load final-mahjong.   [world state: final-mahjong.world]
  8. The goal is that all blocks are on a garbage.
  9. Ok.
 10. Done.
 11. No.

World vocabulary (extracted from the world files loaded above; not part of the dialog):
  Object categories: block, location
  Object attributes: color (green1, red1, yellow1); name (garbage)
  Relations: below1, on1
  Names are as written in the world files, including their trailing 1 (red1, on1).

Source: IJCAI 2019 teaching data for games and puzzles, teaching-data/solitaires/mahjong/.
