# Peg solitaire (second board)

*Task description for a human solver, written 21 November 2026 by Claude, supervised by John E. Laird, from the public sources listed at the end (paraphrased, not quoted).*

Pegs fill the holes of a board except one. A move jumps a peg over a neighbouring peg into an empty hole directly
beyond it, and the jumped peg is removed.

Goal: leave a single peg.

## This instance

Board: init-peg.world; jumped pegs go to a discard area.
