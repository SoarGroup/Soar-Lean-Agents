Tri Peaks Card Solitaire: English input (Rosie teaching script)

The instructor's statements to Rosie, verbatim and in order (script.txt). "Load <name>" sets up the world state in <name>.world in this folder. A bare "Ok." from the instructor answers Rosie's request to set up a state (the puzzle, a failure condition or the goal), "Done." ends the teaching, and the final "No." declines Rosie's offer to solve the task. Rosie's side of the dialog is in dialog.txt; dialog.html shows the dialog with pictures of the world states.

Teaching script:
  1. The name of the puzzle is tri-peaks.
  2. Load init-tri-peaks.   [world state: init-tri-peaks.world]
  3. Ok.
  4. You can move a free block onto a clear garbage.
  5. If a location is not below an object then it is clear.
  6. If a block is clear and the position of the block is absent then it is free.
  7. Load second-tri-peaks.   [world state: second-tri-peaks.world]
  8. If the value of a free block is one less than the value of a top block then you can move the free block onto the top block.
  9. If a block is clear and the position of the block is one then it is top.
 10. If the value of a free block is one more than the value of a top block then you can move the free block onto the top block.
 11. The solution has nine steps.
 12. Load final-tri-peaks.   [world state: final-tri-peaks.world]
 13. The name of the goal is all-trashed.
 14. Ok.
 15. The goal is that all blocks are trashed.
 16. If the position of a block is one then it is trashed.
 17. Done.
 18. No.

World vocabulary (extracted from the world files loaded above; not part of the dialog):
  Object categories: block, location
  Object attributes: name (garbage); position (numeric, 1 to 1); value (numeric, 1 to 6)
  Relations: below1, on1
  Names are as written in the world files, including their trailing 1 (red1, on1).

Source: IJCAI 2019 teaching data for games and puzzles, teaching-data/solitaires/tri-peaks-solitaire/.
